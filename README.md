# homework_3
## RestAssured тесты.<br>
### Описание/Пошаговая инструкция выполнения домашнего задания:
Выбрать два любых метода (https://petstore.swagger.io).<br>
Для каждого метода написать не менее двух автотестов.<br>
Для каждого автотеста в комментариях написать, что мы проверяем.<br><br>

### Инструкция по запуску:
1. Перейдите в корень проекта.
2. В терминале выполните команду:<br>
    mvn clean test
3. Enjoy!<br><br>
**PS.** У вас должен быть локально установлен Maven и JDK 17.<br>
